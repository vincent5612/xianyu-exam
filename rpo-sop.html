二、五步标准流程 核心

从发布职位到入职跟进的完整链路，每步标注所需资源与AI边界

1
发布职位
在Boss直聘、智联招聘发布职位，设置标签管理
🛠 Boss/智联 ⏱ 日常操作 🤖 AI可批量生成职位描述
  • 平台：Boss直聘、智联招聘（主流量来源）
  • 标签管理：职位名称加暗号区分——"农"=农商行，"中"=中行，"招"=招联
  • Boss技巧：每天40~60个招呼，轮转触达（前天的+昨天的+今天的）
  • 智联技巧：招呼量200~400/天，必须雨露均沾
  • 组合策略：持续职位 + 变动职位组合发布，保持曝光
⚠️ 新人常犯错误

一个职位描述打天下，不根据岗位调整关键词 → 曝光低、简历匹配度差。正确做法：每岗至少3个版本的职位描述轮换测试。

2
后台引流 → 加微信
从平台获取简历后，通过电话确认再加微信
🛠 Boss/智联 📞 必须人做：电话确认 🤖 AI可辅助：打招呼模板 🔑 转化率关键节点
  • 分时段触达：早上、中午、下午下班前不同时段
  • 加微前确认：先打电话——在不在深圳、学历、在职情况
  • 微信异常处理：直接电话沟通，意向明确再加微信
  • 平台注意：拿到简历不要马上加微信（避免账号安全风险）
  • 目标指标：每日加微成功30~50人（标准线），50~70人（优秀线）
⚠️ 新人常犯错误

加微信后不马上发自我介绍和岗位信息，等候选人主动问 → 候选人转身就忘了你是谁。添加好友后30秒内必须发第一条信息。

3
微信沟通 → 约面 ⚠️ 最关键节点
像朋友一样沟通，目标明确——确认意向+约定面试时间
📞 必须人做：深度沟通 ⏱ 单人≥20分钟 🤖 AI可辅助：话术参考+跟进提醒
  • 核心原则：像朋友一样沟通。沟通时间至少20分钟起
  • 常见问题：加微后转化率低 → 要么话术问题，要么简历不精准。用反推决策树锁定根因
  • 关键动作：了解候选人真实诉求、解决疑虑、强化岗位优势、锁定面试时间
⚠️ 新人常犯错误

聊3分钟就急着约面试 → 关系不够深，候选人答应后大概率放鸽子。至少聊20分钟：前10分钟建立信任，后10分钟推进约面。

4
面试环节
面试前跟进、到面率保障、面试后跟进
📞 必须人做：面试前跟进 🤖 AI可辅助：面试提醒消息 ⏱ 面试前1-2天跟进
  • 面试前跟进：面试前1-2天必须互动——增强关系+重申岗位优势
  • 到面率低的根因：最后节点沟通+时间确认不到位
  • 通过率：通常50%左右属正常范围
  • 面试后跟进：面试结束当天发消息了解感受，预判候选人意向
⚠️ 新人常犯错误

约好面试就不管了，到时间候选人没来才打电话 → 晚了。面试前一天的晚上必须再确认一次，发现犹豫立即针对性解决。

5
入职跟进
Offer后跟进、入职前维护、在职关怀
📞 必须人做：回访+关怀 🤖 AI可辅助：定时提醒+话术模板 🔑 结算条件
  • Offer后：必须打电话回访，确认入职意向
  • 主观原因（对岗位有顾虑）= 沟通环节没解决 → 需改进流程
  • 客观原因（距离等）= 不可控，记录下来即可
  • 入职前维护：保持热度，防止流失
  • 在职跟进：在岗关怀，促进转介绍
核心原则：宁可约10个人入职8个，也不要约35个人只入职3个。每个节点都要为最终结果负责。

三、微信沟通六要素 V3.0

候选人从加微信到在职跟进的完整生命周期管理

关键洞察：前三个要素决定你的到面率。第一步没做，第二步就尴尬；前两步没做，第三步就会陷入困境——候选人面试通过了还在犹豫要不要去，说明前段内容是缺失的。
1

约面前意向沟通

🎯 目标：建立初始兴趣，获取简历
以岗位最大优势打招呼 → 了解对方情况 → 以工作经验为话题 → 工作内容简单化 → 深化沟通 → 锁定面试时间
2

约面后信任沟通

🎯 目标：增强信任，确认面试
约面成功后15~30分钟是增加信任的最佳时机。发邀约信息后要求回复确认（签字盖章效应），以闲聊为主引入薪资和岗位优势。
3

面试后关系梳理

🎯 目标：维护关系，预判意向
面试结束当天发消息了解感受。预判候选人的入职意向——犹豫的针对性解决，明确的保持热度。
4

Offer沟通

🎯 目标：正式通知，确认入职
正式Offer发出后立即电话沟通，确认入职时间。主动解决候选人最后的顾虑。
5

入职前维护

🎯 目标：保持热度，防止流失
Offer到入职日之间是最容易流失的时期。每隔2~3天互动一次，分享团队情况、岗位亮点。
6

在职跟进

🎯 目标：在岗关怀，转介绍
入职后第1天、第7天、第30天跟进。解决适应问题，发展转介绍——一个满意的员工能带来3个新候选人。

要素一详解：约面前意向沟通七步法

步骤动作要点
A 加微信以岗位最大优势（薪资、福利、岗位）打招呼
B 方向性不仅聊工作，多了解对方情况
C 找话题以过往工作经验为话题，最好往下进行
D 简单化工作性质内容尽量简单，不要过于专业化
E 意向性想找什么工作？之前做什么？深化沟通内容
F 时间性上午10点或下午2点哪个时间方便？
G 问问题多问，让候选人多讲自己的情况

四、标准回答四步法 V3.0

候选人提问后的标准化回复流程。解决核心问题：专员只在等对方问问题，不会主动推进对话

1
✅
正面回答
直接回应候选人的问题，不绕弯子
2
💡
解释问题
拆解问题背后的真实顾虑，先理解再回应
3
🔥
抛优势
回答后立刻补一个岗位亮点，让候选人觉得值
4
❓
引导提问
用反问拿回对话主动权，推进到下一步

实战案例

步骤候选人问：薪资架构没太明白，底薪加绩效吗？
① 正面回答"是的，底薪+绩效"
② 解释问题"底薪2500，绩效新人保护期两个月有2000不用考核"
③ 抛优势"综合新人4500~5500，转正后平均8000~13000，一档社保+公积金"
④ 引导提问"你之前做过类似岗位吗？"
⚠️ 新人常犯错误

候选人问"薪资架构没明白"，专员回答"底薪2500+绩效2000"然后停住等下一个问题——对话终结。
本质：不是在回答问题，是在借问题推进对话。每回答一个问题，必须用一个反问把对话主动权拿回来。

FAB法则在招聘中的应用

用FAB（Feature-Advantage-Benefit）结构化表达岗位优势：

维度解释招聘案例
F — 特点这个岗位有什么底薪2500+绩效
A — 优势相比同行好在哪里新人保护期两个月不用考核
B — 利益对候选人有什么好处前两个月保底4500+，不用担心业绩压力

五、候选人分类沟通法 V3.0

不要吃大锅饭！一个话术打天下是邀约率低的核心原因

三问判断法

问三个问题快速分类：

  1. 你现在收入多少？ — 判断经济驱动力
  2. 之前做什么的？ — 判断行业背景
  3. 对我们的岗位了解多少？ — 判断信息差程度
类别特征核心策略难度
一类：低收入/小白 收入4000~6000，工厂/流水线/应届生 薪资对比法："跨度40%+提升" 低
二类：技术下行 IT/电工等，所在行业萎缩 行业前景对比法："换行稳定" 中
三类：有了解但纠结 知道行业，被负面信息影响 引导面试法："具体到校区谈" 高·可放掉

六、反推决策树 V3.0

结果差 → 往前推 → 找到根因 → 针对性改进。升级为If-Then决策逻辑，每一步告诉你现在该做什么

入职少？
├─ 通过率低？ （面试把关不严？）
├─ ✅ 是 → 检查面试标准：是否严格执行？
├─ ❌ 否 → 到面率低？
├─ ✅ 是 → 面试前有没有跟进？
│ ├─ 有跟进 → 检查跟进内容：是否只说了"记得面试"？
│ └─ 没跟进 → ✅ 立即在面试前1-2天加一步互动
├─ ❌ 否 → 约面成功率低？
│ ├─ ✅ 是 → 微信沟通关系不够深
│ │ └─ ✅ 检查六要素执行情况：是否聊够20分钟？
│ └─ ❌ 否 → 加微转化率低？
├─ ✅ 是 → 后台简历匹配度低
│ └─ ✅ 检查筛选标准+职位描述精准度
└─ ❌ 否 → 后台简历量少？
├─ ✅ 是 → 职位曝光低或打招呼不精准
│ └─ ✅ 调整发布时间段+关键词+打招呼话术
└─ ❌ 否 → ✅ 数据正常，检查其他异常
└─ ❌ 否 → 通过率低？
├─ ✅ 是 → 面试把关标准执行不到位
└─ ❌ 否 → 入职率低？
├─ ✅ 是 → Offer后回访没做到位
│ └─ ✅ Offer后24小时内必须电话回访
└─ ❌ 否 → 客观原因（记录即可）

⚠️ 反推四原则

  • 往下一级推：每次只往上一级找根因，不跳级
  • 数据说话：不要靠感觉判断"好像到面率不高"，要看具体数字
  • 先人后系统：先检查执行是否到位，再怀疑流程有问题
  • 改一个节点测三天：不要同时改多个变量，改一个节点后跑三天数据再判断

七、数据复盘方法论 V3.0

用数据替代感觉，每天早上花5~10分钟做数据复盘

核心数据标准

指标标准优秀警示
每日约面人数3人/天5人/天<2人
每日加微成功30~50人50~70人<20人
Boss沟通量≥150/天200~300/天<80
后台未读—持续99+<50

📋 每日复盘三步骤

  1. 看数据：昨天加了多少微信？约了几个面试？入职了几个？
  2. 反推异常：哪个指标低于标准线？用反推决策树找根因
  3. 定今日动作：今天重点突破哪一个节点？具体做什么？

八、异议处理方法论 V3.0

候选人犹豫时怎么办？标准化异议处理流程

三个核心原则

  • 先认同再转化：不要否定候选人的顾虑——"你说得对，很多人都有这个顾虑"
  • 不争对错，只给视角：候选人说"底薪太低"——不要解释为什么低，给一个他没想到的角度
  • 解决不了不如先放下：有些顾虑当下解决不了（距离、家庭原因），记录后转下一个话题

负面问题转化法

候选人说不要这样回应该这样回
"底薪太低了吧" "这个行业都这样" "新人看底薪，老人看提成。我们团队做了一年的平均8000~13000，你要不要看看他们怎么做到的？"
"我再考虑考虑" "好的那您考虑好了联系我" "理解。你主要顾虑哪方面？距离？薪资？还是岗位内容？我帮你针对性解答。"
"我不太想做销售" "这不是纯销售" "你说得对，这个岗位确实有业绩要求。但跟你理解的可能不一样——公司提供精准客户资源，不用自己找客户，你只负责沟通转化。"
