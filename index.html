体系核心

不是一套操作手册，是一张决策地图

📋

五步标准流程

发布职位 → 后台引流 → 微信沟通 → 面试环节 → 入职跟进。每步标注所需资源与AI边界。

💬

沟通六要素

候选人从加微信到在职跟进的完整生命周期管理。前三个要素决定你的到面率。

🎯

四步回答法

正面回答 → 解释问题 → 抛优势 → 引导提问。借问题推进对话，不被动等待。

🧩

候选人分类

三问判断法快速分类：低收入/小白、技术下行、有了解但纠结。不同策略，不吃大锅饭。

🌳

反推决策树

结果差 → 往前推 → 找到根因 → 针对性改进。If-Then逻辑，告诉你现在该做什么。

📊

数据复盘体系

用数据替代感觉。核心指标：约面人数/加微量/Boss沟通量/后台未读。每天5分钟复盘。

核心方法论

14年实战中验证过的东西，不讲理论，只给框架

🔗

同一套内核

招聘RPO核心能力链条：找到对的人 → 筛选 → 沟通 → 说服 → 成交 → 跟进。不论换什么岗位、什么行业，系统内核永远不变。

⚠️

新人翻车预警

每步配一个实战踩坑案例——聊3分钟就约面试、加微信后不马上发信息、约好面试就不管了。

🤖

AI辅助边界

全链5个环节明确标注：AI能帮什么、AI帮不了什么。不盲目套AI，不幻想工具替代核心环节。

📈

数据驱动

不看感觉看数字。每日约面≥3人、加微30~50人、Boss沟通≥150次。低于标准马上反推根因。
